# 课程 PPT 模板库

为日常上课准备的 PPTX 模板,基于 svg-pptx-engine 的 SVG → PPTX 管线。
**所有装饰仅使用 SVG 的 `<text>` / `<rect>` / `<line>`(以及表格线段),不画任何装饰性形状(圆、多边形、复杂 path)。**

## 目录结构

```
模板/
├── build.js                       # 批量构建脚本
├── 01-学术蓝白/                   # 8 页 · 学术正式风格
├── 02-清新文艺/                   # 8 页 · 人文/文学风格
├── 03-现代极简/                   # 8 页 · 设计/产品风格
├── 04-学科模板/                   # 5 页 · 按学科设计,带图片/视频占位
├── 05-图表模板/                   # 6 页 · 柱/线/占比/表/时间线/流程
└── dist/                          # 构建产物(运行 build.js 后生成)
```

## 风格一览

| 目录 | 主背景 | 主色 | 字体 | 适合场景 |
| --- | --- | --- | --- | --- |
| `01-学术蓝白` | `#FFFFFF` | `#1E3A8A` 深蓝 | sans-serif | 理工 / 文科正式课程、答辩 |
| `02-清新文艺` | `#FAF7F2` 米白 | `#6B7C5C` 莫兰迪绿 | serif | 文学 / 历史 / 哲学 / 艺术 |
| `03-现代极简` | `#FFFFFF` | `#0A0A0A` 黑 + `#EF4444` 红 | sans-serif | 设计 / 产品 / 商业 / 工程实践 |

每套风格都包含 8 个页型:
1. `01-cover` 封面
2. `02-toc` 目录
3. `03-objectives` 学习目标
4. `04-section` 章节封面
5. `05-keypoints` 要点页(编号列表)
6. `06-twocol` 双栏对比
7. `07-summary` 小结(含思考题)
8. `08-closing` 结尾(联系方式)

## 使用方法

### 1. 把模板转成 PPTX

```bash
# 全部模板(共 35 张 PPTX)
node 模板/build.js

# 单个风格
node 模板/build.js 01-学术蓝白

# 单个文件
node 模板/build.js 01-学术蓝白/05-keypoints.svg
```

构建产物在 `模板/dist/<目录名>/<文件名>.pptx`。

> 需要先 `npm run build` 生成 `dist/index.js`(本目录脚本读取该文件)。

### 2. 修改模板内容

直接用任意编辑器打开 SVG,修改文字即可。例如把课程名从「数据结构与算法」改为「线性代数」,只需在 `01-学术蓝白/01-cover.svg` 中替换文字。

修改时注意:
- 不要新增 `<circle>`、`<polygon>`、装饰 `<path>` 等图形元素
- 颜色建议保持在原风格的 4 色以内(背景 + 主色 + 副文字 + 强调)
- 字号梯度保持 36 / 22 / 16 / 13 四档即可

### 3. 加入新课程页

最简单的方式:复制现有 SVG,改文字和占位内容。

新增到 `01-学术蓝白/` 等风格目录,文件名按两位序号递增(如 `09-exercise.svg`),运行 `node 模板/build.js` 即可。

### 4. 在图片/视频占位处替换内容

`lab-photo.svg` 的占位框用 `<rect>` + `stroke-dasharray="8 6"` 绘制成虚线框。
`video-lesson.svg` 用 `<rect fill="#0F172A">` 模拟视频底色。

替换方式有两种:

**A. 在 PPT 中手动替换**(推荐)
1. 打开生成的 PPTX
2. 选中虚线占位框 → 删除
3. 插入 → 图片 / 视频,放置到原位置

**B. 在 SVG 中直接嵌图**
用 `<image href="..." x="..." y="..." width="..." height="..."/>` 替换占位 `<rect>`,
构建脚本会自动把 `<image>` 嵌进 PPTX。

## 设计原则

- **画面尺寸**:全部 `1280 × 720`(16:9 标准 PPT)
- **页边距**:左右 `96px`,顶部 `80-100px`,底部 `60-80px`
- **字号梯度**:大标题 `36-96` / 中标题 `22-28` / 正文 `14-18` / 注释 `11-13`
- **单页颜色**:不超过 4 种
- **每页必有**:左上章节标识 + 右下页码占位(便于多页组合时定位)
