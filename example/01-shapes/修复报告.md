# 01-shapes 修复报告

针对 `example/01-shapes/` 下基础形状 fixture 的两处渲染缺陷,已在 `src/` 中完成修复并通过全部回归用例。

---

## 修复 1 — `01-basic-shapes.svg` panel 2:虚线圆环不显示虚线

### 现象

panel 2 的第二个圆:

```xml
<circle cx="240" cy="110" r="55"
        fill="none" stroke="#8E44AD" stroke-width="3"
        stroke-dasharray="6 4"/>
```

期望:紫色虚线圆环(短划线 6 px / 间隔 4 px)。
实际:实线圆环(`stroke-dasharray` 被忽略)。

### 根因

`src/pptx/utils.ts` 的 `dashArrayToDashType()` 把 SVG 的 `stroke-dasharray` 映射到 pptxgenjs 的预设 `dashType` 枚举(`solid` / `dash` / `lgDash` / `sysDot` …)。原实现对 **两元素数组** 仅判断"是否相等",而 `[6, 4]` 并不相等,直接落入 `default: 'solid'` 分支。

```js
// 旧逻辑:dash !== gap 时 → solid
if (parts.length === 2 && parts[0] === parts[1]) return 'dash'
return 'solid'
```

`[6, 4]` 被当成"自由形虚线"丢弃,等同于无虚线。

### 修复

`src/pptx/utils.ts` `dashArrayToDashType()`:按 dash 段的绝对长度选择最接近的 PPTX 预设。

```ts
if (parts.length === 2) {
  const [dash, gap] = parts
  if (dash <= 1 || gap >= dash * 2) return 'sysDot'  // 点状
  return dash >= 7 ? 'lgDash' : 'dash'                // 短/长划线
}
```

| dasharray   | 旧输出  | 新输出   | 视觉            |
| ----------- | ------- | -------- | --------------- |
| `5 5`       | `dash`  | `dash`   | 标准短划线 ✓    |
| `6 4`       | `solid` | `dash`   | 短划线 ✓        |
| `10 4`      | `solid` | `lgDash` | 长划线 ✓        |
| `2 4`       | `solid` | `sysDot` | 点状 ✓          |

### 验证

`output/01-shapes/01-basic-shapes.pptx` panel 2 的第二个圆现在显示为紫色短划线圆环。

## 修复 2 — `03-rounded-rect.svg` panel 5:`rx ≠ ry` 椭圆角矩形坍缩成胶囊

### 现象

panel 5:

```xml
<rect x="30" y="50" width="240" height="80" rx="40" ry="10" fill="#9B59B6"/>
```

期望:左右两侧凸出的椭圆角(横向半径 40 px,纵向半径 10 px)。
实际:渲染为接近半圆形的胶囊(rx 和 ry 都被当作了 40 或者都被当作了 10)。

### 根因

之前所有带 `rx` / `ry` 的矩形都被映射到 pptxgenjs 的 `roundRect` 预设形状(`<a:prstGeom prst="roundRect">`)。该预设只接受 **一个** `rectRadius`(对应四个角的统一圆角半径),无法表达 SVG 的 `rx ≠ ry` 椭圆角语义。

`src/pptx/converters/shape.ts` `case 'rect'` 旧实现:

```ts
if (rx || ry) {
  options.rectRadius = pxToInch((rx ?? ry) as number)
  shapeName = 'roundRect'
}
```

`rx=40 ry=10` 时只取 `rx`,纵向半径丢失;由于 `rectRadius` 会被 PPTX 按矩形短边夹紧,半径会被压成 min(40, 短边/2) = 40,等同于"两端半圆"。

### 修复

`src/pptx/converters/shape.ts` `case 'rect'`:
- `rx === ry`:保留 `roundRect` 预设(快路径)。
- `rx ≠ ry`:走 `custGeom` 自定义路径,用 `buildRoundedRectPathPoints()` 生成四个角的"四分之一椭圆弧 + 四条边"路径,精确还原椭圆角。

```ts
if (rx !== undefined && ry !== undefined && Math.abs(rx - ry) > 1e-3) {
  const points = buildRoundedRectPathPoints(rect.width, rect.height, rx, ry)
  options.points = convertPathPointsForPptx(points)
  shapeName = 'custGeom'
} else {
  options.rectRadius = pxToInch((rx ?? ry) as number)
  shapeName = 'roundRect'
}
```

新增的 `buildRoundedRectPathPoints(w, h, rx, ry)` 输出 SIF 标准的 `PathPoint[]`,每个角用一个 SVG arc(`ArcCurve`,`largeArc=false`、`sweep=true`)表示,经 `convertPathPointsForPptx()` 转成 PPTX 的中心参数化 `arcTo` 后写入 `<a:custGeom>`。

### 验证

`output/01-shapes/03-rounded-rect.pptx` panel 5 现在显示为左右凸出的椭圆角矩形,而非胶囊形。其余 panel(rx=0、rx=8、rx=20、rx=ry=24)走 `roundRect` 快路径,渲染保持一致,无回归。
